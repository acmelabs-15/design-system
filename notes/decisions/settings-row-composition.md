# Replace settings rows with Field and Item recipes

Remove Setting Row and Setting Rows during the approved migration. Peter selected **Use Field and Item**.

Input settings use horizontal Field so labels, help, errors and control associations stay together. Action rows, such as Transfer Project, use Item with a Button. Shared layout arranges several rows; Fieldset or List adds meaning where appropriate.

The current Setting Row supplies only heading/description/control placement. Chakra Pro already demonstrates horizontal Fields for settings. A dedicated wrapper would add another interface over the selected shared families. Provide complete settings recipes and preserve descriptions, alignment, actions and accessible names.

This does not turn every settings collection into a Fieldset or every action into a form field. Exact recipes and the migration remain inventory/Phase 5 work.
