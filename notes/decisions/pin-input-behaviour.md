# Provide a separate-field Pin Input

Implement Pin Input through the [native Lit/TanStack port strategy](zag-behaviour-ports.md), using Zag behaviour as a source reference. A new Lit component is allowed. Peter selected separate character fields with automatic focus movement, full-code paste, masking and code-autofill support, rather than limiting the control to one native text field.

The earlier actual-package/adapter selection is superseded; the capability choice stands. Port and browser acceptance remain unproven. The inventory must define the exact interface and defaults; this is not implementation approval.

Evidence: [Zag Pin Input](https://zagjs.com/components/pin-input) and [package comparison](../analysis/package-choices.md).
