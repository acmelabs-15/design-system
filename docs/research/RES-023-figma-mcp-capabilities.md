# RES-023: What the Figma MCP can read and write

## Question
What can the Figma MCP read and write today (components, variants, variables, libraries), and what are its limits?

## Answer
The question is answered from Figma's documentation and from the files of the installed plugin. No live call was made, because the Figma MCP is not signed in. Each statement below has a line under Findings, except the lines marked UNVERIFIED.

Sufficient-answer condition, set for IDEA-002#02: each official server with its connection, sign-in and release status; each tool marked read or write, with what it can create or change; what the server cannot do; the limits; the same facts for the installed plugin; both sides of each disagreement.

### Servers

| Server | Address | Connection and sign-in | Status | Writes to files |
|---|---|---|---|---|
| Remote | `https://mcp.figma.com/mcp` | HTTP transport. The person signs in with a Figma account in a browser. Claude Code gets it from the Figma plugin or from `claude mcp add`. Only clients in the Figma MCP catalog can connect. | Recommended by Figma. Its write features are in beta. | Yes |
| Desktop | `http://127.0.0.1:3845/mcp` | A person enables it in Dev Mode of the Figma desktop app. The documentation gives no sign-in step in the client. It needs a Dev or Full seat on a paid plan. | "Intended for specific organization and enterprise needs". | No |
| Government remote | `https://mcp.figma-gov.com/mcp` | Named only in the help center guide. | The developer documentation says Government has the desktop server only. | Not stated |

### What an agent can read and write

Figma calls `use_figma` "the general-purpose tool for writing to Figma files". It runs JavaScript in the file through the Figma Plugin API. It is on the remote server only.

| Subject | Read | Write |
|---|---|---|
| Components | `get_design_context`, `get_metadata`, `get_screenshot`, `search_design_system` (published components), read scripts in `use_figma` | `use_figma`: create, edit and delete components; set `description` and `documentationLinks` |
| Variants and component properties | `get_context_for_code_connect` (properties, variant options), Code Connect markers, read scripts in `use_figma` | `use_figma`: `combineAsVariants` makes a component set; TEXT, BOOLEAN, INSTANCE_SWAP and SLOT properties. An empty component set is not possible. |
| Variables and modes | `get_variable_defs` (variables used in a selection), `search_design_system` (library variables), read scripts in `use_figma` (local collections) | `use_figma`: collections, modes, variables, aliases, scopes, code syntax, bindings to node properties. The plan sets the number of modes. |
| Styles | `get_variable_defs`, `search_design_system` | `use_figma`: text styles, effect styles, paint styles |
| Libraries | `get_libraries` (added and available libraries), `search_design_system` | `use_figma` imports published components, styles and variables by key. No source shows a tool or API that publishes a library. |
| Files and pages | `get_metadata` (page list) | `create_new_file` (Figma Design, FigJam, Figma Slides); `use_figma` creates pages in Figma Design files |
| Images and fonts | `download_assets`, `get_screenshot` | `upload_assets` (PNG, JPG, GIF, WebP, SVG); `generate_image` (uses AI credits). Fonts must be uploaded to the Figma account. |
| Code Connect | `get_code_connect_map`, `get_code_connect_suggestions` | `add_code_connect_map`, `send_code_connect_mappings`. The component must be published first. |
| Text that is not a layer | Read scripts in `use_figma` | Annotations on nodes; Figma Specs (Markdown, open beta) |
| Motion | `get_motion_context` | `use_figma` with the `figma-use-motion` skill. Figma Motion is in open beta. |

`html_to_figma` makes plain layers without components, libraries or variables. `generate_figma_design` captures a running UI as flat layers without a link to libraries; it binds matching variables when the file has a library with variables. `generate_diagram` writes FigJam diagrams. The remaining tools are for Figma Make, generative plugins, shaders and Figma Weave.

### What the sources say it cannot do

- Publish a library: "Components must be published manually before Code Connect mappings can be completed". The bundled Plugin API typings have no publish method.
- Enable a library in a file through the Plugin API (bundled typings), and use `figma.teamLibrary.*` (not implemented in `use_figma`).
- Alias a variable to a variable in another file, or extend a library collection.
- Add a new image from inside `use_figma`; `use_figma` has no network access.
- Use a font that is only on the person's computer.
- Keep state from one `use_figma` call to the next. Each call starts on the first page.
- Import components that contain images or videos, and create GIFs.
- Write anything through the desktop server.

### Limits

| Limit | Value |
|---|---|
| Rate limit, View or Collab seat, every plan | Up to 20 tool calls per month |
| Rate limit, Full or Dev seat | Professional and Education: 200 per day, 10 per minute. Organization: 200 per day, 15 per minute. Enterprise: 600 per day, 20 per minute. |
| Tools that the rate limit covers | "Tools that read data from Figma". Tools that write are exempt; the four examples do not include `use_figma`. |
| Output of one tool call | Up to 20 KB. Claude Code also rejects a response above 25,000 tokens by default. |
| Plans that can write to the canvas | Professional, Education, Organization, Enterprise. Edit access to the file is necessary. |
| Seat for writing | Full seat outside the person's drafts. A Dev seat writes in drafts only. |
| File types for `use_figma` | Figma Design, FigJam, Figma Slides, and Figma Specs in the developer documentation |
| Release status of writing | Beta, "free to use during the beta period", later "a usage-based paid feature". Figma gives no price and no date. |
| Quality statement by Figma | "Output is beta quality and may need manual review and cleanup". Figma advises a test on a duplicate or a draft file. |
| Script run time | A script can fail with "Script exceeded time limit". The plugin advises 20 to 30 variables per call. |
| Variable modes per collection | Starter 1, Professional 4, Organization or Enterprise 40 (plugin files; IDEA-002#15 owns plan facts) |

## Findings

### Servers, connection and sign-in

- Figma documents two ways to connect: a remote MCP server at `https://mcp.figma.com/mcp`, which it recommends and says "offers the broadest set of features", and a desktop MCP server that runs locally through the Figma desktop app and is "intended for specific organization and enterprise needs". Source: https://developers.figma.com/docs/figma-mcp-server/#how-to-connect, checked 2026-11-12.
- The remote server needs no Figma desktop app; a host adds it with the HTTP transport and the URL `https://mcp.figma.com/mcp`, and the person signs in with their Figma account the first time (a browser page with "Allow access"). Source: https://developers.figma.com/docs/figma-mcp-server/remote-server-installation/, checked 2026-11-12.
- For Claude Code, Figma recommends `claude plugin install figma@claude-plugins-official` (MCP server settings plus Figma's skills), with `claude mcp add --transport http figma https://mcp.figma.com/mcp` as the manual route that installs no skills; sign-in is through `/plugin` or `/mcp` and a browser page. Source: https://developers.figma.com/docs/figma-mcp-server/remote-server-installation/#claude-code, checked 2026-11-12.
- Only clients listed in the Figma MCP catalog can connect to the Figma MCP server; a developer of a new client joins a waitlist. Source: https://developers.figma.com/docs/figma-mcp-server/remote-server-installation/, checked 2026-11-12.
- The desktop server runs at `http://127.0.0.1:3845/mcp` after a person clicks "Enable desktop MCP server" in Dev Mode of the Figma desktop app; it needs a Dev or Full seat on a Professional, Education, Organization, Government or Enterprise plan, and it "doesn't support writing to the canvas or sending UI to Figma". Source: https://developers.figma.com/docs/figma-mcp-server/local-server-installation/, checked 2026-11-12.
- The desktop-server page gives no sign-in step for the client: the client adds the local URL and the server works while the desktop app is open with the server enabled. Source: https://developers.figma.com/docs/figma-mcp-server/local-server-installation/#step-2, checked 2026-11-12.
- The developer documentation says Figma for Government supports the desktop server only, with eight tools (`get_screenshot`, `get_design_context`, `get_metadata`, `get_figjam`, `get_variable_defs`, `get_code_connect_map`, `add_code_connect_map`, `create_design_system_rules`); the remote server, `use_figma`, `generate_figma_design`, the Code Connect UI and agent skills are not available there. Source: https://developers.figma.com/docs/figma-mcp-server/local-server-installation/#figma-for-government, checked 2026-11-12.
- Figma's client table lists Claude Code with desktop server support, remote server support, write to canvas (remote only) and a Figma plugin. Source: https://developers.figma.com/docs/figma-mcp-server/#h_01K25F7RBRZKCATVJHNXCS6KXW, checked 2026-11-12.

### Release status

- Writing to the canvas "is currently in beta and free to use during the beta period. It will eventually become a usage-based paid feature". Source: https://developers.figma.com/docs/figma-mcp-server/write-to-canvas/, checked 2026-11-12.
- Figma Specs is in open beta; writing to a spec needs the remote server and edit access to the file. Source: https://developers.figma.com/docs/figma-mcp-server/#what-you-can-do, checked 2026-11-12.

- The tools page lists 18 read tools: `download_assets`, `get_code_connect_map`, `get_code_connect_suggestions`, `get_context_for_code_connect`, `get_design_context`, `get_figjam`, `get_generative_plugin`, `get_libraries`, `get_metadata`, `get_motion_context`, `get_screenshot`, `get_shader`, `get_variable_defs`, `list_file_shaders`, `list_generative_plugins`, `list_shaders`, `search_design_system`, `whoami`. Source: https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/#read-tools, checked 2026-11-12.
- The tools page lists 14 write tools: `add_code_connect_map`, `create_generative_plugin`, `create_new_file`, `create_shader`, `generate_diagram`, `generate_figma_design`, `generate_image`, `html_to_figma`, `send_code_to_figma`, `send_code_connect_mappings`, `update_generative_plugin`, `update_shader`, `upload_assets`, `use_figma`. Source: https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/#write-tools, checked 2026-11-12.
- Of the write tools, only `add_code_connect_map` and `send_code_connect_mappings` are not marked "Remote only"; every tool that writes file content (`use_figma`, `create_new_file`, `upload_assets`, `html_to_figma`, `generate_figma_design`, `generate_image`, `generate_diagram`) is remote only. Source: https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/#write-tools, checked 2026-11-12.
- Of the read tools, `get_libraries`, `search_design_system`, `download_assets`, `get_context_for_code_connect`, `whoami`, `get_generative_plugin`, `list_generative_plugins` and `list_file_shaders` are marked "Remote only"; `get_design_context`, `get_metadata`, `get_screenshot`, `get_variable_defs`, `get_figjam`, `get_motion_context`, `get_code_connect_map`, `get_code_connect_suggestions`, `get_shader` and `list_shaders` are not marked. Source: https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/#read-tools, checked 2026-11-12.
- `use_figma` is "the general-purpose tool for writing to Figma files"; in Figma Design it can create, edit, delete or inspect "pages, frames, components, variants, variables, styles, text, images, and more", and it also supports FigJam, Figma Slides and Figma Specs. Source: https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/#use_figma, checked 2026-11-12.
- `use_figma` works by letting the agent "run code in your Figma file through the Figma Plugin API". Source: https://developers.figma.com/docs/figma-mcp-server/write-to-canvas/#how-it-works, checked 2026-11-12.
- `create_new_file` creates a blank Figma Design, FigJam or Figma Slides file in the person's drafts and asks which team or organization to use when the person belongs to more than one plan. Source: https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/#create_new_file, checked 2026-11-12.
- `get_variable_defs` (Figma Design only) returns the variables and styles used in a selection, such as colors, spacing and typography. Source: https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/#get_variable_defs, checked 2026-11-12.
- `get_libraries` (Figma Design only) lists libraries already added to a file and libraries that can be added, such as Community UI kits and organization libraries, each with name, key, description and source. Source: https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/#get_libraries, checked 2026-11-12.
- `search_design_system` (Figma Design only) searches all connected libraries for components, variables and styles that match a text query. Source: https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/#search_design_system, checked 2026-11-12.
- `get_metadata` (Figma Design only) returns an XML outline with layer IDs, names, types, positions and sizes; without a node ID it returns the file's top-level pages. Source: https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/#get_metadata, checked 2026-11-12.
- `get_design_context` (Figma Design and Figma Make) returns design context and code for a layer or selection, React and Tailwind by default; prompting with the current selection works only with the desktop server, and the remote server needs a link to a frame or layer. Source: https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/#get_design_context, checked 2026-11-12.
- `get_context_for_code_connect` returns component details for Code Connect templates, "including properties, variant options, and nested instances and text layers". Source: https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/#figma-prompted-tools, checked 2026-11-12.
- `upload_assets` uploads PNG, JPG, GIF, WebP and SVG files up to 10 MB each and up to 60 files per call; an SVG is added as editable vector layers. Source: https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/#upload_assets, checked 2026-11-12.
- `html_to_figma` converts a self-contained HTML document (up to 50 MB, up to 20 chosen elements per call) into plain layers that do not use the file's components, libraries or variables. Source: https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/#html_to_figma, checked 2026-11-12.
- `generate_figma_design` sends the live UI of a web app to a new or existing Figma Design file or the clipboard and is available with select MCP clients; it "captures your running UI as flat layers, without a connection to your libraries", but Figma binds matching color, number and string variables when the target file has a library with variables. Source: https://developers.figma.com/docs/figma-mcp-server/code-to-canvas/, checked 2026-11-12.
- The tools page also lists nine Figma Weave tools (`weave_*`), which need a paid standalone Figma Weave account, and one MCP prompt, `create_design_system_rules`. Source: https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/#weave-tools, checked 2026-11-12.

### What the documentation says the server cannot do

- Each tool call can return up to 20 KB of output. Source: https://developers.figma.com/docs/figma-mcp-server/write-to-canvas/#limitations, checked 2026-11-12.
- `use_figma` cannot add new images on its own (the agent uses `upload_assets` or `generate_image`); importing components that contain images or videos, and creating GIFs, are not supported yet. Source: https://developers.figma.com/docs/figma-mcp-server/write-to-canvas/#limitations, checked 2026-11-12.
- Fonts must be uploaded to the Figma account; fonts installed only on the person's computer are not available. Source: https://developers.figma.com/docs/figma-mcp-server/write-to-canvas/#limitations, checked 2026-11-12.
- "Components must be published manually before Code Connect mappings can be completed". Source: https://developers.figma.com/docs/figma-mcp-server/write-to-canvas/#limitations, checked 2026-11-12.
- Figma states that write output "is beta quality and may need manual review and cleanup" and tells people to test on a duplicate of a library or a draft file before changing production files. Source: https://developers.figma.com/docs/figma-mcp-server/write-to-canvas/#limitations, checked 2026-11-12.

### Limits by plan and seat

- Writing to the canvas is for Professional, Education, Organization and Enterprise plans, in Figma Design, FigJam and Figma Slides, with edit access to the file and a supported client on the remote server. Source: https://developers.figma.com/docs/figma-mcp-server/write-to-canvas/, checked 2026-11-12.
- Writing to the canvas needs "a Full seat to write outside your drafts". Source: https://developers.figma.com/docs/figma-mcp-server/#what-you-can-do, checked 2026-11-12.
- Rate limits per seat: View and Collab seats get up to 20 tool calls per month on every plan; Full and Dev seats get up to 200 per day and 10 per minute on Professional, 200 per day and 15 per minute on Organization, 600 per day and 20 per minute on Enterprise; the Starter plan has no Full or Dev row; Education matches Professional. Source: https://developers.figma.com/docs/figma-mcp-server/rate-limits-access/#rate-limits, checked 2026-11-12.
- "Rate limits apply to tools that read data from Figma. Some tools are exempt, including tools that write to Figma files", with `add_code_connect_map`, `create_new_file`, `generate_figma_design` and `whoami` named as examples; `use_figma` is not in that list of examples. Source: https://developers.figma.com/docs/figma-mcp-server/rate-limits-access/#rate-limits, checked 2026-11-12.
- Most tools use no Figma AI credits; `generate_image` and `send_prompt` do, and Weave tools use Weave credits. Source: https://developers.figma.com/docs/figma-mcp-server/rate-limits-access/#ai-credits, checked 2026-11-12.
- The rate-limits page names a `send_prompt` tool, but the tools page index does not list a tool of that name; its Figma Make section describes only `send_code_to_figma`. Source: https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/#figma-make-code-layers, checked 2026-11-12.
- The MCP server works only with files the signed-in account can already access; `whoami` returns the email, plans and seat on each plan. Source: https://developers.figma.com/docs/figma-mcp-server/rate-limits-access/#permission-errors, checked 2026-11-12.
