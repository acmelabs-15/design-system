Best Practices#

When to use

  • Marketing pages, docs landings and feature breakdowns where the rule lines are part of the design; plain CSS grid for app content.

Behavior

  • Set columns and rows at every breakpoint; solid cells for opaque tiles; hide guides only when it helps; never nest more than one level; guides are aria-hidden.
