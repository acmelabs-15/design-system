Best Practices#

When to use

  • Persistent associated context: deployment details, log row inspection, a member profile. Modal for a blocking decision, Drawer for mobile.

Behavior

  • Outside click does not close, so always render Close and honor Escape; trap focus and return it to the trigger row.

Content

  • Title Case title naming the entity (Deployment Details); read-mostly body; buttons Verb + Noun.
