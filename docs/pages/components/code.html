Code: a bordered block (radius 5, padding 24, 32px vertical margins) of source in 13/20 mono with syntax highlighting. The default slot's text is the source; `syntax` names its language (`javascript`, `tsx`, `json`, `bash`, …); tokens carry `token <kind>` so the kinds' colors apply.
