Copy Button

A button that copies a given string to the clipboard and shows that it did.

<acme-copy-button>

Default#

<acme-copy-button text-to-copy="lipsum" label="copy text"></acme-copy-button>

API#

Every reactive property reflects from its attribute; array and object values take JSON in the attribute. Events bubble and are composed.

<acme-copy-button>AcmeCopyButton

Copy button. An icon-only button (secondary, square, medium by default) that writes `text-to-copy` to the clipboard. Its icon is a stack of two layers, the check and the copy glyph, that swap for one second after a successful copy (or while `copied` is set), with an assertive status line for screen readers. A failed copy raises an error toast. Fires `acme-copy` on success and `acme-copy-error` on failure; a slotted `icon` replaces the copy glyph.
