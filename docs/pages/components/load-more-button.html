<acme-load-more>AcmeLoadMore

Load more button. A full-width secondary submit button that appends more items to a list, 16px below it; the slot is the text, "Load More" by default. `loading` shows the spinner and disables it; `no-gap` removes the space above; `no-border-radius` squares the corners so it sits flush with the list; `placeholder` renders an empty block of the same height instead.
