Calendar

Select a date or a range from a calendar behind a button.

<acme-calendar>

Range#

The trigger is a secondary button labelled with the chosen range; the popover holds the range form and the month grid. Shown static here.

<acme-calendar static range value="2026-09-08" end="2026-09-12"></acme-calendar>

Single date#

<acme-calendar static value="2026-09-15"></acme-calendar>

Presets#

Real buttons for the common ranges.

<acme-calendar static range presets='[{"label":"Last 7 Days","days":7},{"label":"Last 30 Days","days":30},{"label":"Month to Date","days":9}]'></acme-calendar>

Closed#

Without static, the calendar opens from the button and closes on Escape or a pick.

<acme-calendar value="2026-09-15" min="2026-01-01"></acme-calendar>

API#

Every reactive property reflects from its attribute; array and object values take JSON in the attribute. Events bubble and are composed.

<acme-calendar>AcmeCalendar

Geist Calendar: a date or range picker in a popover behind a secondary button. Values are ISO dates.

Best Practices#

Behavior

  • Min and max bound the retention window; the timezone can be pinned; Apply commits the range.

Content

  • Presets are Title Case (Last 7 Days, Month to Date); the trigger reads the chosen range.
