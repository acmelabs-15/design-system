Text With Copy Button

Display text alongside a button that copies the text to the clipboard.

<acme-text-copy>

Default#

<acme-text-copy ellipsis success-message="Copied to clipboard" text-label="Copy" text-to-copy="lipsum"></acme-text-copy>

With Small and Tertiary#

<acme-text-copy ellipsis success-message="Copied hashed digest to clipboard" text-label="Copy config digest" text-to-copy="edgeConfigData.digest"></acme-text-copy>

API#

Every reactive property reflects from its attribute; array and object values take JSON in the attribute. Events bubble and are composed.

<acme-text-copy>AcmeTextCopy

Text with copy button. A full-width text button: the label (a `p` by default; `as` picks the tag) beside a 16px icon that swaps from the copy glyph to a check for one second after a copy. The leaving layer shrinks and fades (`data-phase="exiting"`) while the next one mounts. Renders nothing without `text-to-copy`. `ellipsis` truncates the label; `show-tooltip` shows the text to copy on hover; `success-message` goes out as a toast after a copy, and a failed copy raises an error toast. Fires `acme-copy` on success. The label is the `text` part.
