Relative Time Card

A popover that shows a given date in local time.

<acme-relative-time>

Default#

The trigger renders the short form; hover shows the moment in UTC and local time.

<div class="row" style="gap:32px">
  <acme-relative-time date="1789002000000"></acme-relative-time>
  <acme-relative-time date="1788900000000"></acme-relative-time>
  <acme-relative-time date="1788300000000"></acme-relative-time>
</div>

Static#

The card pinned open.

<div style="min-height:140px">
  <acme-relative-time static open date="1789002000000"></acme-relative-time>
</div>

API#

Every reactive property reflects from its attribute; array and object values take JSON in the attribute. Events bubble and are composed.

<acme-relative-time>AcmeRelativeTime

Best Practices#

When to use

  • Recent timestamps in tables, entity rows, deploy lists and feeds; past 7 days in prose, render Mar 14, 2026 directly.

Content

  • Pass the date as epoch ms; the formatter produces 2m, 5h, Yesterday and already includes ago; children only for non-time labels (Just now, Queued).
