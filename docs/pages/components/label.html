Label

Accessible text label for form controls.

<acme-label>

Default#

This is a label
<acme-label>This is a label</acme-label>

With input#

Input carries its own label; use acme-label for a control that has none.

<acme-input label="Email Address" type="email" placeholder="Enter email address..." style="max-width:280px"></acme-input>
