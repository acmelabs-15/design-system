Best Practices#

When to use

  • Multi-select in lists and acknowledgments. A single boolean setting is a Toggle.
  • Indeterminate is a visual state driven by a parent, not a third value.

Content

  • An acknowledgment label is a full sentence with a period.
  • A row-select box carries aria-label="Select {row name}".
