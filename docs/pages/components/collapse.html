API#

Every reactive property reflects from its attribute; array and object values take JSON in the attribute. Events bubble and are composed.

Best Practices#

Behavior

  • One open at a time when exclusive, several when independent; closed by default; never nested more than one level.
  • Content stays in the DOM when closed; the trigger carries aria-expanded.

Content

  • Title Case topic names (Advanced Settings); no destructive primary action inside.
