JSON View

Render JSON objects and arrays as a collapsible tree with syntax coloring.

<acme-json-view>

Default#

Levels below expand-depth start collapsed.

<acme-json-view data='{"deployment":{"id":"dpl_9WjH8QFQySx7","project":"docs","target":"production"},"request":{"method":"GET","status":200},"cached":false,"error":null}'></acme-json-view>

Expanded#

<acme-json-view expand-depth="3" data='{"deployment":{"id":"dpl_9WjH8QFQySx7","regions":["iad1","sfo1"]}}'></acme-json-view>

Highlighted#

Search matches in field names and values.

<acme-json-view expand-depth="2" highlight="request" data='{"level":"error","requestId":"req_00042","message":"Deployment request failed","statusCode":500}'></acme-json-view>

API#

Every reactive property reflects from its attribute; array and object values take JSON in the attribute. Events bubble and are composed.

Best Practices#

When to use

  • JSON the reader inspects, collapses, selects or copies; a code block for static documentation.

Behavior

  • Depth 1 for logs and detail surfaces, 0 for dense tables; highlight only during an active search; keep the text selectable.
