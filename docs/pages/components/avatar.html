Avatar

Avatars represent a user or a team, and stacked avatars a group.

<acme-avatar><acme-avatar-group>

Group#

Each member carries a 1px ring in the page color and overlaps the next; the first sits on top.

abcdefgh
<acme-avatar-group>
  <acme-avatar>ab</acme-avatar>
  <acme-avatar>cd</acme-avatar>
  <acme-avatar>ef</acme-avatar>
  <acme-avatar>gh</acme-avatar>
</acme-avatar-group>

Stacking order#

Add reverse so the last member sits on top.

abcdef
<acme-avatar-group reverse>
  <acme-avatar>ab</acme-avatar>
  <acme-avatar>cd</acme-avatar>
  <acme-avatar>ef</acme-avatar>
</acme-avatar-group>

Limit#

Over the limit, the last slot is a +N counter.

abcdefghijklmn
<acme-avatar-group limit="3">
  <acme-avatar>ab</acme-avatar>
  <acme-avatar>cd</acme-avatar>
  <acme-avatar>ef</acme-avatar>
  <acme-avatar>gh</acme-avatar>
  <acme-avatar>ij</acme-avatar>
  <acme-avatar>kl</acme-avatar>
  <acme-avatar>mn</acme-avatar>
</acme-avatar-group>

Image#

A src with an alt; the fallback letters show until it loads.

A 16px service dot at the bottom right.

pkpkpk

  <acme-avatar presence="away">pk</acme-avatar>

</div>

One or two uppercase letters, weight 500, on a gray fill.

API#

Every reactive property reflects from its attribute; array and object values take JSON in the attribute. Events bubble and are composed.

<acme-avatar>AcmeAvatar

Geist Avatar: 16 / 24 / 32 / 48 / 64, round; letters at weight 500 on a gray fill.

Best Practices#

When to use

  • 20–24px next to label-14, 32px next to label-16, 48–64px in headers.
  • A placeholder is a loading shell, never a permanent fallback.
