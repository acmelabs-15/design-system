Best Practices#

When to use

  • Power-user shortcuts over a row, file or canvas object; every item also exists in a visible Menu or row button.

Behavior

  • Position at the pointer, flip before clipping; close on activation, Escape and outside click, never on hover-out; Shift+F10 opens it from the keyboard.
