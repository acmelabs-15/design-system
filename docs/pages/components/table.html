API#

Best Practices#

When to use

  • Rows that share a shape with at least one comparable column. Entity for a row with one action; Description for key/value metadata.

Behavior

  • Empty list: an Empty State outside the table. Unknown cells show an em dash. Sortable headers are buttons; numeric columns are tabular.

Content

  • Title Case noun headers (Last Used, Requests (7d)); short relative times in cells; pager copy Page 2 of 7 or 21–40 of 142.
