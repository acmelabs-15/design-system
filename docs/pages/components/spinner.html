Best Practices#

When to use

  • Indeterminate single-action waits of one to three seconds: submit buttons, an inline refresh, a row-level retry. For buttons, the Button loading state.

Behavior

  • Mount only when the action starts; pair waits over a second with copy naming the work; aria-busy on the wrapper.
