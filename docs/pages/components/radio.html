Best Practices#

When to use

  • Two to six mutually exclusive options where seeing every option matters. Past six, Select or Combobox; binary, Toggle; rich options, Choicebox.

Content

  • Group label is a Title Case noun in a legend; option labels stay parallel (Monthly / Yearly); a disabled option gets a tooltip naming why.
