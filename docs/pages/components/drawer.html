Drawer

Content in a separate view that slides up from the bottom on small viewports.

Shown static here; in a page it is fixed to the bottom over a 40% black scrim.

API#

Every reactive property reflects from its attribute; array and object values take JSON in the attribute. Events bubble and are composed.

Best Practices#

When to use

  • Small viewports only; Modal or Sheet on desktop; never for a destructive confirmation.

Behavior

  • Tap-outside and swipe-down dismiss; body scroll locked; focus trapped and returned; Escape and the system back gesture close it.
