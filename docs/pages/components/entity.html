Best Practices#

When to use

  • Member rows, integration rows, domain rows. Table for sortable columns; Description for a static key/value block.

Content

  • Lead with an avatar or icon, a Title Case label, then sentence-case metadata; right-column buttons are Verb + Noun (Remove Member).
