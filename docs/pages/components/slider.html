Slider

Select a value from a range.

<acme-slider>

Default#

<acme-slider value="50" aria-label="Volume"></acme-slider>

With label#

<acme-slider label="Volume" value="40"></acme-slider>

Disabled#

<acme-slider value="25" disabled aria-label="Volume"></acme-slider>

API#

Every reactive property reflects from its attribute; array and object values take JSON in the attribute. Events bubble and are composed.

Best Practices#

When to use

  • Ranged numeric input where shape matters more than precision. Pair with a numeric Input for exact values; snap to a sensible step; show the live value in tabular numbers with its unit.
