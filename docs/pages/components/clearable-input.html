API#

Every reactive property reflects from its attribute; array and object values take JSON in the attribute. Events bubble and are composed.

<acme-clearable-input>AcmeClearableInput

A text field that clears itself: an acme-input whose end place is a clear button with an Esc key once the field has a value, and Escape clears too. `cmdk` shows ⌘ K keys instead, which slide to Esc while the field has a value (`data-animate` on the field). Clearing fires `acme-input` and `acme-clear` and returns focus to the field. Form-associated and labelable.
