Breadcrumbs

Show the path to the current page and let the reader step back up it.

<acme-breadcrumbs>

Text#

Plain links and a final span with aria-current; the element inserts the separators.

HomeProjectscoding-agent-template
<acme-breadcrumbs>
  <a href="#">Home</a>
  <a href="#">Projects</a>
  <span aria-current="page">coding-agent-template</span>
</acme-breadcrumbs>

Disabled item#

HomeArchive2025
<acme-breadcrumbs>
  <a href="#">Home</a>
  <span class="disabled">Archive</span>
  <span aria-current="page">2025</span>
</acme-breadcrumbs>

Menu type#

Each item is a 22px button on background-200.

acme-labscoding-agent-templateSettings
<acme-breadcrumbs variant="menu">
  <a href="#">acme-labs</a>
  <a href="#">coding-agent-template</a>
  <span aria-current="page">Settings</span>
</acme-breadcrumbs>

API#

Every reactive property reflects from its attribute; array and object values take JSON in the attribute. Events bubble and are composed.

<acme-breadcrumbs>AcmeBreadcrumbs

Geist Breadcrumbs: text type, or `menu` type chips. Children: acme-breadcrumb or plain a/span.
