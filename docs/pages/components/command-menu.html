Best Practices#

Behavior

  • Focus trapped; an aria-live result count; groups keep the visible label first so typeahead matches.

Content

  • Title Case Verb + Noun items (Deploy Project); page labels Title Case; placeholders sentence case ending with …; group names 1–2 words.
