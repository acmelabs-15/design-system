Best Practices#

When to use

  • Deployment lifecycle only: QUEUED, BUILDING, READY, ERROR, CANCELED, DELETED. Other statuses use a Badge.

Behavior

  • The dot animates while building or queued and goes static in a terminal state; no separate spinner beside it.

Content

  • The label sentence-cases the state; never wrap it in Status: Ready.
