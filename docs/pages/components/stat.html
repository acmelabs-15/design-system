Stat

The one component for a headline figure: label and context, the value with its unit and trend, then a delta, a description, a meter, a spark or a foot.

<acme-stat><acme-stat-delta><acme-stat-desc><acme-stat-foot><acme-spark>

Cells#

Stats sit in the cells grid; each is a cell.

API#

Every reactive property reflects from its attribute; array and object values take JSON in the attribute. Events bubble and are composed.
