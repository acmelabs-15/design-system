Icons

The icons the elements draw themselves, and the sprite the docs examples use for prefix, suffix and icon slots.

Built-in glyphs#

Elements render these from glyph(name) in base.ts, so a page needs no sprite for a component's own icons: the copy button's check, the menu's lock, the note's alert. 24-box strokes at 16px.

Slot icons#

Example markup passes icons into slots as inline SVG. Any 24-box stroke icon works; the docs use a sprite of symbols with #i-<name> ids, referenced as <svg class="ic"><use href="#i-check"/></svg>. In an artifact, inline the paths you use.

<acme-button>
  <svg class="ic" width="16" height="16" slot="prefix" viewBox="0 0 24 24">
    <path d="M20 6 9 17l-5-5"/>
  </svg>
  Save
</acme-button>
