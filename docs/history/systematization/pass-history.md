## Why this library exists, and what this pass is for

`@acmelabs/design-system` is the design system, as Lit web components with the `acme-` prefix. It exists so AI-generated artifacts stop guessing at a design language: it is version-tracked, standardized, and renders in the static HTML pages Claude uses for artifacts, which is why it is Lit and not React. The first passes ported vercel.com/geist one-to-one in style, behavior and functionality. The [historical port plan](../parity-port-plan.md) records that work and its settled fixes.

**The pass moved beyond parity.** Its goal was to standardize the library: one name for one concept, one shape for one kind of interface, and fewer elements, built from a small set of primitives flexible enough that the rest of the library composes them. Overlapping bordered-box arrangements were candidates for a shared container or documented primitive recipe. Removals, renames and replacements were part of that goal.

The original brief used “I” for Peter.
