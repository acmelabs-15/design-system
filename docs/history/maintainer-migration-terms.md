# Maintainer migration terms

These terms describe the records of the maintainer workflow migration of 2026-10. They are not product contexts.

- A baseline identifies the source revision and the inputs and results whose scope is being verified.
- The migration ledger maps each original file to a destination or a justified retirement.
- A batch is a bounded group with named files and acceptance checks.
- Byte preservation means the source and destination contain exactly the same bytes, including final newlines.

The [migration evidence index](../verification/workflow-migration/README.md) owns the detailed mappings and checks. An evidence report is not a task queue.
