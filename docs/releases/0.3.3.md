# Release 0.3.3: MCP dependency advisory

Status: published 2026-10-27. All five packages are public and verified, the GitHub release is the latest, and issue #9 is closed.

## Scope

[Issue #9](https://github.com/acmelabs-15/design-system/issues/9) reports that `@acmelabs/design-system-mcp` 0.3.2 pins `zod` at exactly 4.6.5. Every `zod` version below 4.6.6 has a high advisory, [GHSA-mrhx-c7xc-m3w5](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5). The exact pin stops consumers from getting the fix without a new release.

This release changes no component behaviour and no product contract. It changes dependency declarations, the lockfile and the coordinated version:

- The MCP package declares `zod ^4.6.7` and `@modelcontextprotocol/sdk ^1.32.0`, as [decision 0116](../decisions/0116-mcp-dependency-ranges.md) selects.
- The lockfile moves four packages with high findings: `zod` 4.6.5 to 4.6.7, `body-parser` 2.3.0 to 2.4.0, `happy-dom` and `@happy-dom/global-registrator` 20.14.0 to 21.0.4, and the `npm/undici` entry 8.11.2 to 8.12.3.
- The same operation moves three MCP runtime packages with moderate or low findings: `fast-uri` 3.1.9, `ip-address` 10.7.5 and `qs` 6.17.0. The `npm/ip-address` entry also moves to 10.7.5.
- All five packages, their core peer versions, the README CDN examples and version table, the seven consumer-skill records and the lockfile workspace entries move to 0.3.3.
- A [manifest test](../../packages/mcp/__tests__/package.test.ts) fails when an MCP runtime dependency is not a caret range. The workspace install test restores the manifest's own `zod` value instead of a hard-coded 4.6.5.

The `npm/undici` entry describes no installed file. The pinned `npm` 12.0.2 bundles `node-gyp` 13.0.0 and `undici` 6.27.0, outside the advisory range. Bun records a resolution for the bundled dependency that it never installs, and `bun audit` reads it. [Issue 006](../../.scratch/maintenance/issues/006-bun-bundled-dependency-lock.md) records this underlying defect.

The completed maintainer-workflow plan moves to [tasks/done/maintainer-workflow](../../tasks/done/maintainer-workflow/plan.md). Its links in the specification index, the maintainer-workflow specification, decision 0057 and research 20 move with it.
