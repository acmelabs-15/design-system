# Triage labels

Adapted from mattpocock/skills, MIT, commit c55ee46, through brain's setup templates.

The local tracker maps brain's five roles to these Status: values.

| Role | Status value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | The maintainer has not evaluated the issue |
| needs-info | needs-info | More information is needed from the reporter or owner |
| ready-for-agent | ready-for-agent | The work is specified for an agent to implement |
| ready-for-human | ready-for-human | A human must perform the work |
| wontfix | wontfix | The issue will not be actioned |

Use the mapped value when a skill names a role. Keep completion evidence in the issue; a status change alone does not prove the result.
