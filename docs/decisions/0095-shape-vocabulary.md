# Separate overall shape from corner treatment

Use circle for a circular outline, pill for fully rounded ends and square for equal width and height. Corner radius describes a separate treatment; square does not mean sharp corners. Peter selected “Separate the concepts” over combined shape presets.

Decided 2026-09-19 by Peter.

The 2026-09-19 review found rounded/pill/shape aliases that sometimes requested the same appearance. The approved migration replaces ambiguous or duplicate authoring paths. This does not choose every component's supported shapes, exact radius values or property design, or expand the selected needs-based shape-morphing scope.
