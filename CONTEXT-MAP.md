# Context map

## Contexts

- [Component library](CONTEXT.md): the elements, content and arrangements used to build artifacts.
- [Generation and comparison tools](tools/geist/CONTEXT.md): the reference descriptions, style generation and measurements used to check the library.

## Relationships

The tools describe and measure the component library. Shared component terms are defined in the component glossary and referenced from the tooling glossary; they are not defined twice. A tooling root is a measured box, while a component is a reusable part of the library.
